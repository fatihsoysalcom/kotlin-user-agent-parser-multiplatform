# Kotlin User Agent Parser Multiplatform

This Kotlin Multiplatform example demonstrates a basic User-Agent string parser. It extracts browser and operating system information from common User-Agent strings, showcasing platform-agnostic parsing logic.

## Language

`kotlin`

## How to Run

Save the code as UserAgentParser.kt and run it using the Kotlin compiler: kotlinc UserAgentParser.kt -include-runtime -d UserAgentParser.jar && java -jar UserAgentParser.jar
